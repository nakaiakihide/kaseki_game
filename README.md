# 企画メモ：カセキ発掘 × 遺伝子交配バトル（タイトル未定）

作成：2026-11-19（あっきーの発案、ジャービスと壁打ち）

## コンセプト
カセキホリダーの「発掘 → クリーニング → 復活」に、遺伝子交配（配合）を掛け合わせて、新しい生物を生み出していくスマホアプリ。

## コアループ
発掘 → クリーニング → 復活 → 交配（新生物誕生） → バトル → 図鑑に登録 → もっと掘る

## 方向性（決定済み）
- **バトル系**でいく（2026-11-19 ユーザー決定。「バトル系が1番燃える」）
- 検討した他の方向：図鑑埋め系（軽いがマネタイズと目的が弱い）、街づくり系（生物を住まわせる箱庭。うんこワールド試作の3D技術が転用可能）。ハイブリッド案もあったがバトル系に決定

## バトル仕様（有力案）
ドラクエモンスターズ式が一番しっくりくる（ユーザー見立て）：
- 3体パーティ、コマンド選択 or 「さくせん」AIに任せる方式
- 配合で特技も遺伝する（特技継承が育成の目的になる）
- 実装は数値と特技の設計が本体で、派手なアニメなしでも成立する
- 最初はCPUとの大会形式で十分。オンライン対戦は人気が出てから

## 独自性（カセキホリダー側の味）
- 入手経路が DQM のスカウトではなく「発掘 → クリーニング」
- 化石は部位別（あたま・どうたい・うで・あし）。部位を揃えて復活させる
- クリーニングの出来で個体差が出る案（きれいに掘れた化石ほど強い／レア形質つき）
- 発掘パートはスマホの指で削る操作と相性がいい（元はDSのタッチペン操作）

## 最大の課題と解決策：キャラ量産
交配前提だと「全キャラを手描き」は破綻する。解決策は **遺伝子データ＋パーツ合成**：
- 生物1体 = 遺伝子データ（体の形・頭・角・翼・尻尾・模様・色・サイズ・特技…）
- 交配 = 両親の遺伝子を部位ごとに継承。優性形質は出やすく、たまに突然変異
- 見た目はパーツのレイヤー合成で自動生成。新種が生まれるたびに新しい姿が勝手に生まれる
- 描く量の試算：体8種 × 頭8種 × 角6種 × 翼4種 × 尻尾6種 × 模様5種 × 色 → パーツ数十個で組み合わせ数十万通り
- 名前も形質から自動生成すると「新種発見」感が出る

## AI生成の扱い（コスト検証済み）
- プレイ中に毎回AI生成する方式は**不成立**：API画像生成は1枚数円〜数十円の従量課金。1万人 × 1日10回 × 5円 = 1日50万円の試算。生成待ち（数秒〜数十秒）と画風ブレの問題もある
- AIの使いどころは「開発時」：パーツや模様の素材をAIで量産して同梱する（一回きりのコスト）
- 生成を使うなら「突然変異の激レア個体だけ生成してサーバー保存・全員で共有」のような回数が限られた枠のみ
- パーツ合成ならプレイ中の生成コストはゼロ。残るのはサーバー代（オンライン要素がある場合）などの固定費のみ
